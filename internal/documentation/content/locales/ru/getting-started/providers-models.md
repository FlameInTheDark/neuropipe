# Провайдеры и модели

В Neuropipe одновременно используется один активный провайдер. Выберите его в разделе **Настройки → Провайдер**.

## Поддерживаемые режимы

- **Ollama** подключается к уже работающему локальному endpoint Ollama.
- **Управляемый llama.cpp** скачивает принадлежащий Neuropipe рантайм и модель GGUF, затем привязывает их только к loopback.
- **Совместимый с OpenAI** подключается к настроенному пользователем совместимому endpoint.

## Настройка локальной модели

В разделе **Настройки → Модели** найдите публичный GGUF-репозиторий, выберите квантизацию и установите её в настроенную папку содержимого. Установка проверяет LFS SHA-256, если Hub его предоставляет, и сохраняет локальные метаданные рядом с моделью. Выберите установленную модель в **Настройки → Рантайм**, затем запустите управляемый рантайм.

Очередь LLM ограничивает количество одновременных задач модели. Установите один поток, если локальный рантайм не умеет обслуживать параллельные запросы.

Учётные данные провайдеров остаются в защищённом Windows хранилище. Предпросмотры узлов, журналы, экспорты и диагностика плагинов скрывают раскрытые секреты.
