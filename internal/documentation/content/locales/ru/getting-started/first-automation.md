# Первая автоматизация

В этом примере кнопка отправляет уведомление на рабочий стол.

## Создание

1. Создайте пайплайн и добавьте **Button Trigger**.
2. Перетащите связь от exec-пина **Start** к **Desktop Notification**.
3. Укажите заголовок и текст уведомления в инспекторе.
4. Нажмите **Запустить**, чтобы проверить черновик. Журнал выполнения показывает входы, выходы и ошибки каждого узла.
5. Опубликуйте корректный граф. Кнопка появится на панели триггеров.

## Осознанное подключение данных

Чтобы добавить вычисленное значение в сообщение, соедините чистый выход **Format Text** или **Get Field** с пином данных Message. Уведомление всё равно выполняется только после импульса на его exec-входе.

```text
Button Trigger ──exec──> Desktop Notification
Format Text ──data──> Desktop Notification.Message
```

Сведения о возможностях и ошибках см. в [Desktop Notification](docs:reference/local).
