# Случайное число

## Назначение
Генерирует случайное число при каждом выполнении Blueprint с необязательными границами диапазона и выбором между дробным (float) или целочисленным (integer) результатом.

## Настройка
- **Тип**: `float` для дробного значения из `[0, 1)` (или вашего диапазона), `integer` для целого числа.
- **Использовать диапазон**: при включении узел выбирает значение внутри `[От, До]` вместо `[0, 1)`.
- **От**: включительная нижняя граница диапазона.
- **До**: включительная верхняя граница диапазона.

## Входы
Пины данных **От** и **До** необязательны. При подключении их значения имеют приоритет над полями инспектора, поэтому вышестоящие узлы могут динамически управлять диапазоном. Если **Использовать диапазон** выключено, границы игнорируются.

## Пример
`Триггер-кнопка → Случайное число (integer, диапазон 1–6) → Уведомление рабочего стола` показывает результат броска кубика. Подключите `Получить переменную` к пину **От**, чтобы управлять нижней границей во время выполнения.
