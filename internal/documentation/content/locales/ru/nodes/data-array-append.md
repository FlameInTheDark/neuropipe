# Добавить в массив

## Назначение

Добавляет значение в список и возвращает новый список. Узел чистый: он никогда не изменяет подключённый массив, поэтому исходный список остаётся доступным для других узлов.

## Входы

- **Массив**: расширяемый список.
- **Значение**: добавляемый элемент.

## Выход

- **Массив**: новый список с добавленным элементом.

## Конфигурация и пример

Подключите **Массив** к выходу `Разобрать JSON`, а **Значение** — к узлу Константа. Несколько узлов «Добавить в массив» подряд собирают список элемент за элементом. Если **Массив** не является списком, исполнение запрашиваемого пути завершится ошибкой.
