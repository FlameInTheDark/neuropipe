# Добавить в массив

## Назначение

Добавляет данные в список и возвращает новый список. Узел чистый: он никогда не изменяет подключённый массив, поэтому исходный список остаётся доступным для других узлов.

Режим **Добавление** определяет, что означает вход «Значение»: **Один элемент** добавляет значение как единственный элемент — подключённый здесь список вложится как один элемент. **Элементы массива** выполняет склейку: элементы подключённого списка добавляются по одному, поэтому `[3, 4]` после `[1, 2]` даёт `[1, 2, 3, 4]`.

## Входы

- **Массив**: расширяемый список.
- **Значение**: добавляемый элемент или список.

## Выход

- **Массив**: новый список с добавленным.

## Конфигурация и пример

Подключите **Массив** к выходу `Разобрать JSON`, а **Значение** — к узлу Константа. Чтобы объединить два списка, выберите **Элементы массива** и подключите **Значение** ко второму списку. Несколько узлов «Добавить в массив» подряд собирают список элемент за элементом. Если **Массив** не является списком, исполнение запрашиваемого пути завершится ошибкой; в режиме **Элементы массива** **Значение** тоже должно быть списком.
