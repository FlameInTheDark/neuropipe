# Разобрать объект

Разделяет объект на настраиваемые типизированные пины выхода.

## Настройка

Подключите объект к пину **Источник**. У каждого выхода есть стабильный ID,
имя, путь с точками и тип. `клиент.имя` читает вложенное значение, а
`items.0.name` может читать элемент списка.

Для известных результатов встроенных узлов кнопка **Настроить автоматически**
создаёт все документированные поля. После этого сопоставления можно свободно
редактировать.

## Пример

Результат терминала → Разобрать объект (`terminal.output`) → LLM-промпт.
