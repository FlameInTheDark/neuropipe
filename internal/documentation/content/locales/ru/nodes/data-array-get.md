# Взять из массива

## Назначение

Читает элемент списка по индексу, отсчитываемому от нуля.

## Входы

- **Массив**: список, из которого извлекается элемент.
- **Индекс**: целочисленный индекс элемента (с нуля).

## Выход

- **Значение**: элемент по указанному индексу.

## Конфигурация и пример

Подключите **Массив** к списку (например, из `Запрос JSON`), а **Индекс** — к числовому узлу. Отрицательный, нецелый или выходящий за границы индекс завершится ошибкой.

Кроме того, **Индекс** можно задать прямо в инспекторе узла, если входной пин
Индекса не подключён. Подключённый провод всегда имеет приоритет над
настроенным значением.
