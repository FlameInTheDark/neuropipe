# Определить тип

## Назначение

Сообщает JSON-тип любого значения: `text`, `number`, `boolean`, `object`, `list` или `null`. Для списков выход **Тип элемента** возвращает общий тип элементов.

## Выходы

- **Тип**: JSON-тип значения.
- **Тип элемента**: для списка — общий тип элементов, иначе пусто.

## Конфигурация и пример

Для списка **Тип элемента** равен `any` (пустой список), `mixed` (элементы разных типов) или одному из перечисленных JSON-типов.
