# Показать диалог ввода

## Назначение
Показывает стилизованное диалоговое окно с заголовком, сообщением, полем ввода с подписью и кнопками «Продолжить»/«Отмена». Выполнение блокируется до ответа пользователя. «Продолжить» выдаёт типизированное значение на пин «Значение» и продолжает с пина «Продолжить»; «Отмена» продолжает с пина «Отменено» и выдаёт nil на пин «Значение».

## Настройка
- **Заголовок**: текст в заголовке диалога.
- **Сообщение**: текст в теле диалога, обычно подсказка к ожидаемому вводу.
- **Подпись поля**: подпись рядом с полем ввода.
- **Тип ввода**: `text` принимает любую строку, `number` разбирает ввод как число с плавающей точкой и завершает выполнение с ошибкой при некорректном значении. Выходной пин «Значение» следует этому типу.

## Пример
`Триггер-кнопка → Показать диалог ввода (number) → Продолжить → Математика: Сложить (использовать пин «Значение»), Отменено → Уведомление рабочего стола`. Пин «Значение» равен `nil`, когда пользователь отменил ввод.
