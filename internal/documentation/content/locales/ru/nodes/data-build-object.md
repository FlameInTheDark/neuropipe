# Собрать объект

Создаёт типизированный объект из настраиваемого числа пинов данных. У каждой
строки в **Полях** есть стабильный ID пина, поэтому переименование пина или
ключа объекта не разрывает существующие соединения.

## Настройка

Задайте имя пина, тип данных и ключ объекта для каждого значения. Пути с
точками, например `клиент.имя`, создают вложенные объекты. Ключи должны быть
непустыми, уникальными и не пересекаться.

## Пример

**Имя** → `клиент.имя` и **E-mail** → `клиент.email` создают:

~~~json
{"клиент":{"имя":"Ада Лавлейс","email":"ada@example.com"}}
~~~
