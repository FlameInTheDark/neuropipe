# JavaScript

## Назначение

Выполняет небольшое синхронное действие JavaScript в текущем запуске Blueprint. В **Редакторе кода** объявляются типизированные входы и выходы. Программа должна вернуть один объект с ключами, точно совпадающими с ID настроенных выходов. Неявных преобразований нет: значения должны удовлетворять объявленному `TypeSpec`.

## Пример

Объявите обязательный вход `name` и выход `message` как **Текст** в выборе типа:

```js
return { message: `Привет, ${name}!` };
```

Вход также доступен как `inputs.name`.

## Чтение входов

ID входов становятся локальными переменными JavaScript: настроенный пин
`name` доступен как `name`. Каждый пин также находится в объекте `inputs`, в
том числе для динамического доступа:

```js
const direct = name;
const property = inputs.name;
const dynamic = inputs["name"];
const label = inputs.optionalLabel ?? "Без названия";
return { message: `${direct}: ${label}` };
```

ID пинов должны быть корректными идентификаторами JavaScript, например
`userName`, `count` или `filePath`. Имена вроде `first-name`, `inputs` и `np`
отклоняются. Отсутствующий обязательный вход безопасно останавливает узел;
`??` используйте только для необязательных пинов.

## Системный API и безопасность

`np` содержит только ограниченные локальные помощники для переменных, Base64, хешей, сводок, отчётов, чата и уведомлений. Доступ к файлам и сети требует соответствующей возможности, включённой в редакторе. Объекты Go, секреты и дескрипторы хоста не доступны. Полное описание API приведено в руководстве **Узел JavaScript**.
