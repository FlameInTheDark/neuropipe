# Показать вопрос

## Назначение
Показывает собственное диалоговое окно с кнопками «Да» и «Нет». Выполнение блокируется, пока пользователь не выберет вариант, затем продолжается с соответствующего exec-пина, чтобы граф мог ветвиться по решению пользователя.

## Настройка
- **Заголовок**: текст в заголовке диалога.
- **Сообщение**: текст в теле диалога. Сформулируйте его как вопрос «да/нет».

## Пример
`Триггер-кнопка → Показать вопрос (Сообщение: Отправить отчёт сейчас?) → Да → HTTP-запрос, Нет → Уведомление рабочего стола (пропущено)`. Выход «Результат» сообщает, какую кнопку нажал пользователь (`yes` или `no`).
