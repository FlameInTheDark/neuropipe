# Извлечение HTML

## Назначение
Извлекает точные значения из HTML-документа с помощью CSS-селекторов — так же, как узел HTML в n8n. Каждый настроенный запрос создаёт собственный типизированный выходной пин.

## Настройка

Подключите HTML-документ ко входу **HTML**, затем добавьте извлечения в инспекторе. Каждое извлечение задаёт:

- **Название пина** для выходного провода.
- **CSS-селектор** для поиска элементов, например `h1.title` или `ul li a`.
- **Возвращаемое значение**: **Текст** (текстовое содержимое элемента), **HTML** (разметка элемента) или **Атрибут** (атрибут вроде `href`; при выборе появляется поле имени атрибута).
- **Вернуть все совпадения**: выключено — первый совпавший элемент как Текст; включено — все совпадения как список значений Текст.

Выходы используют только стандартные типы данных (Текст или Список), поэтому результаты напрямую соединяются с «Форматировать текст», «Цикл для каждого», «Объединить текст», Regex и любым другим узлом.

Отсутствие совпадений по селектору — не ошибка: выход будет пустым текстом или пустым списком в режиме «все совпадения». Недопустимый CSS-селектор или дублирующееся имя пина приводит к ошибке валидации до запуска пайплайна.

## Пример
`HTTP-запрос → Извлечение HTML (селектор `a.product`, возвращаемое значение: Атрибут `href`, все совпадения) → Цикл для каждого`.

Комбинируйте с переключателями HTTP-запроса **Удалить скрипты** и **Удалить стили**, чтобы передавать экстрактору чистую разметку.
