# Кодировать Base64

## Назначение

Явно кодирует выбранный вход **Байты** или **Текст** в Base64. Выберите входное
и выходное представления независимо. Выход Байты — последовательность Base64,
а Текст — её форма UTF-8.

## Пример

`Прочитать файл (Байты) → Кодировать Base64 → HTTP-запрос`.

Каждый выбор меняет точный тип провода. Подключённые значения не
переинтерпретируются, не разбираются и не преобразуются неявно.
