# SQL

## Назначение

Выполняет один SQL-запрос в зарегистрированной локальной базе SQLite. Выберите
базу, введите SQL и задайте именованные параметры. Значения передаются через
типизированные входные пины.

## Параметры и результаты

Используйте имена вроде `:userId` и настройте параметр `userId`. Узел выводит
`Columns`, `Rows`, `Rows affected`, `Last insert ID` и `Truncated`, а затем
исполнительный выход `Then`.

Запросы возвращают не более 500 строк. Позиционные параметры и несколько
инструкций отклоняются.
