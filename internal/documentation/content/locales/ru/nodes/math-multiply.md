# Умножить

## Назначение

Умножает два числа. Чистый узел вычисляется, только когда другой узел запрашивает его выход Result, и не имеет пинов выполнения.

## Пины

**A** и **B** — числовые входы; **Result** — числовой выход.

Если пины не соединены, **A** и **B** можно задать прямо в инспекторе. Подключённый числовой пин имеет приоритет; оба ручных значения по умолчанию равны `0`.

## Ошибки и пример

Оба входа должны быть конечными числами; переполнение отклоняется. `Цена` × `Константа 1,2` даёт скорректированную цену.
