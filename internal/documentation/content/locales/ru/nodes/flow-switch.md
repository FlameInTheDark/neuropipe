# Переключатель

## Назначение

Switch — это impure-узел управления потоком Blueprint. Импульс Exec получает
значение из пина **Значение**, проверяет случаи по порядку и запускает ровно
один Exec-выход: первый совпавший или **По умолчанию**.

## Пины и настройка

- **Exec** запускает сравнение; **Значение** принимает данные любого типа.
- У каждого случая есть типизированное литеральное значение и видимое
  **название пина**. Внутренний ID пина не меняется при переименовании.
- Случаи проверяются сверху вниз. Первый истинный результат побеждает;
  **По умолчанию** выполняется, если совпадений нет.

Равно и Не равно работают с текстом, числом и Boolean. Содержит, Начинается с
и Заканчивается на требуют текст. Варианты Больше/Меньше требуют число.
Neuropipe не выполняет неявных преобразований: `"5"` не равно `5`.

## Пример

Подключите `Get Field priority` к **Значению**. С компаратором `Содержит`
случай `urgent` отправляет срочное уведомление, `review` создаёт отчёт, а
**По умолчанию** продолжает обычный поток.
