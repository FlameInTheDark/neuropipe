# Показать сообщение

## Назначение
Показывает собственное диалоговое окно с заголовком, сообщением и кнопкой OK. Выполнение блокируется, пока пользователь не закроет окно, затем продолжается с пина «Затем».

## Настройка
- **Заголовок**: текст в заголовке диалога.
- **Сообщение**: текст в теле диалога. Поддерживается многострочный текст.

## Пример
`Триггер-кнопка → Показать сообщение (Заголовок: Готово, Сообщение: Пайплайн завершён)`. Подключите `Форматировать текст` к пину **Сообщение**, чтобы показать динамические значения.
