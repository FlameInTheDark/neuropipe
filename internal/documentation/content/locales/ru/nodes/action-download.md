# Скачать из Интернета

## Назначение
Скачивает файл по URL и сохраняет его в локальную папку. Имя файла берётся из последнего сегмента пути URL.

## Настройка
- **URL**: полный HTTP(S)-адрес файла для скачивания. URL должен содержать сегмент пути, который станет именем локального файла.
- **Расположение**: абсолютный путь к папке назначения. Папка создаётся при необходимости.

## Пример
`Триггер-кнопка → Скачать из Интернета (URL: https://example.com/report.pdf, Расположение: C:\\Downloads) → Уведомление рабочего стола`. Подключите `Константа` (text) к пину **URL**, чтобы скачивать URL, выбранный во время выполнения.
