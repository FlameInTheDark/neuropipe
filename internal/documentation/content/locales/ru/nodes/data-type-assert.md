# Проверка типа

## Назначение

Сужает значение `any` до явного контракта типа Blueprint V3 без преобразования. Узел проверяет во время выполнения примитивы, списки, карты и поля записей; при несовпадении запуск безопасно прекращается.

## Пример

`Получить поле → Проверка типа ({"kind":"record","fields":[{"name":"id","type":{"kind":"string"}}]}) → Собрать объект`.

Используйте **Преобразовать тип**, когда примитив нужно преобразовать. Используйте **Проверка типа**, только если значение уже соответствует выбранному контракту.
