# Прочитать файл

## Назначение

Читает одобренный локальный файл, не изменяя данные. В инспекторе выберите
**Байты** или **Текст** для единственного пина результата. Текст доступен
только при корректном UTF-8; иначе выберите Байты.

## Пример

`Наблюдение за файлом → Прочитать файл → Разобрать JSON → Цикл для каждого`.

В **Кодировать Base64** и **Декодировать Base64** явно выберите входное и
выходное представления. Ни один узел не преобразует данные неявно.
