# Получить глобальную переменную

## Назначение
Читает переменную с областью действия рабочего пространства, общую для всех
пайплайнов и запусков. Чтение до первой записи возвращает заявленное значение
по умолчанию переменной.

Переменная выбирается из списка объявленных имён, управляемых на экране
**Переменные**. Чтения безопасны при одновременно работающих пайплайнах.

## Пример
`Получить глобальную переменную (visits) → Сложение → Сохранить глобальную
переменную`, чтобы накапливать счётчик между запусками.
