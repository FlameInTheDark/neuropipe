# Список каталога

## Назначение

Выводит файлы, папки и символические ссылки из одобренного локального
каталога. Каждая запись содержит имя, абсолютный путь, размер в байтах, тип,
дату создания, если её предоставляет ОС, и дату изменения.

## Пример

`Кнопочный триггер → Список каталога → Цикл для каждого → Проверка типа`.

Пин **Файлы** — типизированный список записей. Подключите его к обобщённому
циклу или используйте **Проверка типа** перед узлом, которому нужна точная
структура записи.
