# Local Webhook

Событие Local Webhook запускает доверенный опубликованный пайплайн, когда
Neuropipe получает корректно подписанный HMAC HTTP-запрос. Сначала включите
слушатель в **Настройки → API и вебхуки**.

## Пины

- **Start** — exec-выход к первому узлу действия или потока.
- Выход данных содержит объект запроса. Через **Get Field** можно
  типизированно прочитать json.event, json.repository или body.

## Конфигурация

| Поле | Обязательно | Описание |
| --- | --- | --- |
| **Path** | Да | Используйте отдельный путь, например /build-complete. Крайние косые черты нормализуются. |
| **Signing secret** | Да | Секрет из защищённого Windows-хранилища Neuropipe. Он не появляется на холсте и в журнале. |

Доставка выполняется на POST http://<адрес>:<порт>/hooks/<путь>. Для
/build-complete на стандартном слушателе:
http://127.0.0.1:7878/hooks/build-complete.

## Аутентификация запроса

Укажите X-Neuropipe-Signature в виде
sha256=<шестнадцатеричный HMAC-SHA-256 сырого тела>. Neuropipe
время-независимо сравнивает точные сырые байты. Переформатированный JSON,
другие переводы строк или кодировка приводят к ошибке. Этот HMAC
аутентифицирует вебхуки; bearer-токен остаётся для /v1.

## Создаваемые значения

При корректном запросе выход содержит:

- trigger: webhook;
- body: сырое тело как текст;
- json: распарсенное тело, если это валидный JSON.

Для {"event":"build.completed","build":42} добавьте в **Get Field**
json.event как текст и json.build как число.

## Выполнение и доверие

Вебхуки автономны. В очередь попадает только включённая опубликованная
привязка триггера с доверием к этой точной ревизии. После публикации изменений
может требоваться новое доверие. Принятый запрос возвращает **202 Accepted** и
запись выполнения; последующие действия ещё могут выполняться или завершиться
ошибкой.

## Ошибки

Выключенный API, неизвестный или выключенный путь, отсутствующий секрет,
неверная подпись или недоверенная ревизия не запускают пайплайн. Валидный HMAC
не исключает последующие ошибки: отказ возможности или ошибку провайдера
смотрите в отредактированном журнале выполнения.

## Пример

~~~text
Local Webhook → Get Field (json.repository, json.status)
              → Branch (status == "success") → Create Report
~~~

Полная настройка, примеры подписи и поиск проблем описаны в
[API и вебхуки](docs:concepts/api-webhooks).
