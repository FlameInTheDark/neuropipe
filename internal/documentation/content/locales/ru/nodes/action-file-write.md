# Записать файл

## Назначение

Записывает выбранное значение **Текст** или **Байты** в одобренный локальный
путь. Селектор типа содержимого меняет точный контракт входа. Байты должны
прийти через подключённый пин Байты и не разбираются из текстового редактора.

## Пример

`Чтение файла (Байты) → Запись файла (Байты)`.
