# Разделение по регулярному выражению

## Назначение

Разделяет **Текст** по каждому совпадению Go RE2. Задайте **Шаблон** в
инспекторе или подключите текстовый пин, чтобы переопределить сохранённое
значение для текущего запуска.

## Выходы

- **Части** имеют точный тип `list[string]`.
- **Разделений** — точное целое число найденных разделителей.
- **Есть совпадение** показывает, встречается ли шаблон во входном тексте.

Начальные и конечные пустые части сохраняются. Если совпадений нет, Части
содержат один исходный текст, Разделений равно нулю, а Есть совпадение=false.

## Пример

Используйте текст `one, two; three` с шаблоном `[,;]\s*`. Части будут
`["one", "two", "three"]` и могут быть напрямую переданы в **For Each**.

## Синтаксис RE2

Шаблоны используют безопасный синтаксис Go RE2, а не PCRE. Lookahead,
lookbehind и обратные ссылки в шаблоне не поддерживаются. Некорректные
выражения завершаются явной ошибкой; значения не-текстового типа никогда не
преобразуются в текст.
