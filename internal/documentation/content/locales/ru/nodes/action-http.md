# HTTP-запрос

## Назначение
Вызывает HTTP-эндпоинт и передаёт текстовый или JSON-ответ в граф.

## Настройка

- **URL** и **Метод** задают адрес и глагол запроса.
- **Тело** отправляется как JSON, если не настроен заголовок `Content-Type`.
- **Заголовки запроса** — редактор «ключ–значение». Повторяющиеся имена
  отправляются как отдельные заголовки.
- Включите **Использовать свой User-Agent**, чтобы показать поле User-Agent.
  Оно заменяет любой `User-Agent`, заданный в списке заголовков.
- **Удалить скрипты** убирает элементы `script` и `noscript` из тела HTML-ответа;
  **Удалить стили** убирает элементы `style` и ссылки `link rel="stylesheet"`.
  Оба оставляют тело без изменений для не-HTML-ответов, например JSON.

Узел выполняется только по импульсу на входе выполнения. Заголовки — это
конфигурация, а не пин данных, и сами по себе запрос не запускают.

## Результат

Объект результата содержит HTTP-код состояния, тело ответа, заголовки ответа и
разобранный JSON, если тело — корректный JSON. Любой ответ 4xx или 5xx
останавливает текущее выполнение и попадает в журнал запуска.

## Пример
`Триггер-кнопка → HTTP-запрос → Создать отчёт`; соедините Результат с «Получить поле» для свойства JSON.
