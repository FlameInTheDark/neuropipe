# Поиск по регулярному выражению

## Назначение

Проверяет **Текст** регулярным выражением Go RE2 и возвращает каждое
совпадение как типизированную структуру. Подключите Текст и задайте **Шаблон**
в инспекторе либо подключите текстовый пин Шаблон, чтобы переопределить
сохранённое значение на текущем запуске.

## Выходы

- **Есть совпадение** равно true, если найдено хотя бы одно совпадение.
- **Количество** — точное целое число совпадений.
- **Совпадения** имеет тип `list[RegexMatch]` с полями `text`, `startByte`,
  `endByte` и `captures`.

Каждая группа захвата — это `RegexCapture` с индексом `index` от единицы,
именем `name` (пустым для неименованной группы), `matched`, `text`,
`startByte` и `endByte`. Неучаствующая необязательная группа безопасна:
`matched=false`, текст пустой, оба смещения равны `-1`. Смещения задаются в
байтах UTF-8, как в пакете Go `regexp`.

Отсутствие совпадения не является ошибкой: Есть совпадение равно false,
Количество равно нулю, а Совпадения — пустой список.

## Пример

Используйте шаблон `(?P<name>\w+)=(?P<value>\d+)` с текстом
`limit=25 retries=3`. Совпадения содержит две записи. Первая содержит
`limit=25` и именованные группы `name` (`limit`) и `value` (`25`).

## Синтаксис RE2

Шаблоны используют безопасный движок RE2 из Go. Именованные группы имеют вид
`(?P<name>...)`. Lookahead, lookbehind и обратные ссылки в шаблоне не
поддерживаются. Некорректный шаблон завершает узел ошибкой без преобразований
или догадок.
