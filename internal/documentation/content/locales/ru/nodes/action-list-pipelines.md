# Список пайплайнов

## Назначение
Возвращает все опубликованные пайплайны воркспейса в виде структурированных
данных, чтобы поток мог анализировать сам каталог — фильтровать его, выбирать
цель для узла Run Pipeline или передавать имена в отчёты и уведомления.

## Выходы
- **Then**: exec-продолжение после сбора списка.
- **Pipelines**: список объектов с полями `id`, `name`, `description`,
  `status` и `publishedRevision`. Пайплайны без публикации не включаются.
- **Count**: количество записей в списке.

## Настройка
У узла нет настроек; каталог читается заново при каждом запуске.

## Пример
`Ручной триггер → Список пайплайнов → JavaScript (выбор по имени) → Run Pipeline`
