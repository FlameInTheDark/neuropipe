# Сохранить глобальную переменную

## Назначение
Записывает переменную с областью действия рабочего пространства, общую для
всех пайплайнов и запусков. Значение мгновенно доступно в памяти и сохраняется
в локальную базу данных не чаще одного раза в секунду, поэтому оно переживает
перезапуск приложения.

Узел выполняет одну из трёх операций, выбранных в инспекторе:

- **Установить** перезаписывает значение, проверяя его на соответствие
  заявленному типу данных.
- **Увеличить** атомарно добавляет число, предотвращая потерянные
  обновления при одновременно работающих пайплайнах.
- **Добавить** атомарно добавляет элемент в список.

## Пример
`Триггер расписания → Сохранить глобальную переменную (lastRun, операция:
Установить)`, чтобы записать время последнего запуска обслуживающего
пайплайна.
