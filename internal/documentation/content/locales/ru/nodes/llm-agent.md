# Агент

## Назначение

Выполняет ограниченную задачу, используя только явно подключённые опубликованные инструментальные функции LLM.

## Пин «Инструменты»

Вход **Инструменты** — декларативный неограниченный пин инструментов, а не Exec-пин. Подключите к нему единственный выход **Tool** каждой опубликованной инструментальной функции LLM. Агент передаёт провайдеру только эти функции; неподключённую функцию вызвать нельзя.

Каждый вызов сверяется с именем опубликованной функции, точными типами входов, обязательными входами и подсказками для модели. Результат функции передаётся JSON-объектом в следующий ход модели. Ошибочный аргумент получает безопасную ошибку контракта, поэтому модель может повторить вызов в пределах лимита ходов.

## Пример

`Получить прогноз города.Tool → Агент.Инструменты`, затем `Триггер-кнопка → Агент → Создать отчёт`.
