# Локальные узлы

Локальные узлы действий используют ограниченное разрешение возможностей. Настраивайте только папки и репозитории, к которым должна обращаться опубликованная ревизия.

## Список файлов папки

**Назначение:** выводит прямые файлы, папки и символические ссылки из одобренной папки. **Пины:** вход/выход выполнения, вход «Путь», выход «Список файлов». **Возвращает:** `name`, `path`, размер в байтах, `type` (`file`, `directory` или `symlink`), `updatedAt` и `createdAt`, если платформа предоставляет это время. **Разрешение:** чтение файлов. **Ошибка:** отсутствующие, недоступные для чтения или не одобренные папки завершают узел с ошибкой. **Пример:** Триггер-кнопка → Список файлов папки → Цикл для каждого.

## Чтение файла

**Назначение:** читает локальный файл, не изменяя его байты. **Пины:** вход/выход выполнения, вход «Путь», один выход результата. **Настройка:** выберите Байты или Текст для результата. **Возвращает:** выбранное представление; Текст для содержимого не в UTF-8 безопасно завершится ошибкой. **Разрешение:** чтение файлов. **Ошибка:** отсутствующие или не одобренные пути завершают узел с ошибкой. **Пример:** Наблюдение за файлами → Чтение файла → Кодировать Base64.

В **Кодировать Base64** и **Декодировать Base64** явно выбираются входные и выходные представления Текст или Байты. Ни один локальный узел не выполняет это преобразование неявно.

## Запись файла

**Назначение:** записывает текст или сырые байты. **Пины:** вход/выход выполнения, входы «Путь»/«Содержимое», объект результата. **Настройка:** путь, тип содержимого и текстовое содержимое при выборе Текста. **Возвращает:** записанный путь и булево значение. Байты должны прийти через подключённый пин Байты и никогда не разбираются из текста. **Разрешение:** запись файлов. **Ошибка:** ошибки доступа к родительской папке и записи фиксируются. **Пример:** Чтение файла (Байты) → Запись файла (Байты).

## Запуск команды терминала

**Назначение:** запускает PowerShell, Windows PowerShell или cmd. **Пины:** вход/выход выполнения, входы «Оболочка»/«Команда»/«Рабочая папка», объект результата. **Настройка:** оболочка и команда. **Возвращает:** команду и объединённый вывод. **Разрешение:** терминал. **Ошибка:** отмена, ошибки команд и недопустимые рабочие папки останавливают узел. **Пример:** Триггер-кнопка → Запуск команды терминала → Получить поле `terminal.output`.

## Уведомление рабочего стола

**Назначение:** показывает уведомление Windows. **Пины:** вход/выход выполнения, входы «Заголовок»/«Сообщение», объект результата. **Настройка:** заголовок и сообщение. **Возвращает:** показанные заголовок/сообщение. **Разрешение:** не требуется. **Ошибка:** ошибки уведомлений на неподдерживаемых платформах фиксируются. **Пример:** Ветвление «Истина» → Уведомление рабочего стола.

## Git

**Назначение:** запускает целевую операцию Git. **Пины:** вход/выход выполнения, входы «Операция»/«Репозиторий», объект результата. **Настройка:** поддерживаемая операция и репозиторий. **Возвращает:** операцию и вывод. **Разрешение:** Git. **Ошибка:** ошибки репозитория и команды фиксируются. **Пример:** Cron-триггер → Git status → Создать отчёт.
