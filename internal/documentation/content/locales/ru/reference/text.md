# Текстовые узлы

Текстовые узлы работают только с точными значениями Text без неявных
преобразований. **Split** возвращает `list[string]`, сохраняя пустые сегменты,
а **Join** принимает только такой список. **Contains**, **Starts With** и
**Ends With** учитывают регистр. **Replace** заменяет первое совпадение,
заданное положительное количество или все совпадения; пустой поиск явно
завершается ошибкой.

**Index Of** и **Substring** используют смещения в кодовых точках Unicode.
Для отсутствующего значения Index равен `-1`; неверный диапазон завершается
ошибкой.
