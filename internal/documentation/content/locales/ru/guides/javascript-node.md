# Узел JavaScript

Узел **JavaScript** предназначен для небольших детерминированных преобразований и локальной оркестрации. Он использует чистый Go-интерпретатор Goja, работает синхронно и не раскрывает объекты Go приложения напрямую.

## Создание типизированного шага

1. Добавьте **Код → JavaScript** и выберите **Редактировать код**.
2. Добавьте входы и выходы: их ID становятся переменными JavaScript, а все входы также доступны через `inputs`.
3. Выберите тип каждого пина в визуальном редакторе. Он поддерживает примитивные типы, списки с типизированными элементами, map с текстовыми ключами и типизированными значениями, а также структурные объекты с именованными обязательными или необязательными полями. Neuropipe сохранит полученный `TypeSpec`; редактировать JSON не нужно.
4. Верните объект со всеми настроенными выходами. Каждое вложенное значение проверяется, неявных преобразований нет.

```js
const titles = tasks.filter((task) => !task.done).map((task) => task.title);
return { titles, count: titles.length };
```

## Чтение входных пинов в коде

Каждый ID настроенного входа становится локальной переменной JavaScript. Вход с именем `name` можно прочитать как `name`; все входы также доступны в объекте `inputs`, что удобно для динамического ключа:

```js
const greeting = `Привет, ${name}!`;
const sameName = inputs.name;
const selected = inputs["name"];
return { greeting };
```

Используйте для ID каждого пина корректный идентификатор JavaScript, например `userName`, `count` или `filePath`. ID вроде `first-name`, `inputs` и `np` отклоняются. Если обязательный вход отсутствует, узел безопасно останавливается. Для необязательного входа задайте явное значение по умолчанию, например `const label = inputs.label ?? "Без названия"`.

## API `np`

`np` предоставляет `context`, `uuid`, `assert`, `fail`, переменные запуска, явные Base64- и SHA-256-помощники, сводки пайплайнов/функций/запусков, отчёты, чат и уведомления. `np.files.list/readBytes/readText/writeBytes/writeText` требуют соответствующих прав на файлы. `np.http.request({ url, method?, headers?, body? })` требует сетевого доступа и возвращает `status`, `headers` и текстовый `body`.

## Возможности и ограничения

Каждая включённая возможность показывается в запросе доверия при публикации и повторно проверяется во время запуска. Скрипт не может получить доступ через импорт, путь или скрытый API хоста. Код проверяется перед сохранением; асинхронное ожидание, импорты, процессы, секреты и Go-дескрипторы недоступны.
