# Twitch EventSub

В **Настройки → Twitch** укажите публичный Client ID и подключите учётную
запись через диалог device code. Токены остаются в защищённом хранилище Windows
и никогда не передаются в renderer.

**Twitch Event Trigger** выбирает событие, имя канала и учётную запись авторизации.
Укажите Twitch-логин (например, `your_channel`), а не числовой ID: Neuropipe
получит его локально.
Для сообщений чата доступны Text, Command text, Broadcaster ID, Author ID и
Message ID. По умолчанию префикс сравнивается без учёта регистра; одновременно
должны совпасть и префикс, и список авторов.

Для ответа подключите Message ID к Reply to message ID узла **Send Twitch Chat
Message**. Нужна capability network; сообщения длиннее 500 символов отклоняются
без разбиения.

Для команды с фильтром автора задайте, например, префикс `!mod` и разрешённые
числовые ID авторов в **Author IDs**. Должны совпасть и префикс, и автор; Text
остаётся исходным.
