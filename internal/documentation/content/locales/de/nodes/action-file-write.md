# Datei schreiben

## Zweck

Schreibt einen ausgewählten Wert **Text** oder **Bytes** in einen freigegebenen
lokalen Pfad. Die Auswahl des Inhaltstyps ändert den genauen Eingangsvertrag.
Bytes müssen über einen verbundenen Bytes-Pin kommen und werden nicht aus dem
Texteditor geparst.

## Beispiel

`Datei lesen (Bytes) → Datei schreiben (Bytes)`.
