# Datei lesen

## Zweck

Liest eine freigegebene lokale Datei ohne ihre Daten zu verändern. Wählen Sie
im Inspector **Bytes** oder **Text** für den einzelnen Ergebnis-Pin. Text ist
nur bei gültigem UTF-8 verfügbar; andernfalls wählen Sie Bytes.

## Beispiel

`Dateiüberwachung → Datei lesen → JSON parsen → Für-jedes-Schleife`.

Mit **Base64 kodieren** und **Base64 dekodieren** wählen Sie die Ein- und
Ausgabe-Repräsentation ausdrücklich. Kein Knoten konvertiert Daten
stillschweigend.
