# Verzeichnis auflisten

## Zweck

Listet Dateien, Ordner und symbolische Links in einem freigegebenen lokalen
Verzeichnis auf. Jeder Eintrag enthält Name, absoluten Pfad, Größe in Bytes,
Typ, Erstellungszeit, wenn das Betriebssystem sie liefert, und Änderungszeit.

## Beispiel

`Button-Trigger → Verzeichnis auflisten → Für-jedes-Schleife → Typzusicherung`.

Der Pin **Files** ist eine typisierte Liste von Records. Verbinden Sie ihn mit
einer generischen Schleife oder verwenden Sie vor einem Knoten mit einem
genauen Eintragsvertrag **Typzusicherung**.
