# Écrire un fichier

## Objectif

Écrit une valeur sélectionnée **Texte** ou **Octets** dans un chemin local
approuvé. Le sélecteur de type de contenu modifie le contrat exact de l’entrée.
Les Octets doivent arriver par une broche Octets connectée et ne sont pas
analysés depuis l’éditeur de texte.

## Exemple

`Lire un fichier (Octets) → Écrire un fichier (Octets)`.
