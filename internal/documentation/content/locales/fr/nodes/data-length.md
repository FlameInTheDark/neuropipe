# Longueur

## Objectif

Compte les éléments d’une liste, les caractères d’un texte ou les clés d’un objet.

## Sortie

- **Longueur** : le nombre comme valeur numérique.

## Configuration et exemple

La longueur d’un texte se mesure en caractères, pas en octets. Tout autre type de valeur échoue avec une erreur claire.
