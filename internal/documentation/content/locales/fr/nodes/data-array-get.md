# Lire dans un tableau

## Objectif

Lit l’élément à un index de base zéro dans une liste.

## Entrées

- **Tableau** : la liste à parcourir.
- **Index** : index entier de base zéro de l’élément.

## Sortie

- **Valeur** : l’élément à l’index indiqué.

## Configuration et exemple

Connectez **Tableau** à une liste (par ex. depuis `Interroger JSON`) et **Index** à un nœud numérique. Un index négatif, non entier ou hors limites échoue avec une erreur claire.

Sinon, vous pouvez définir **Index** directement dans l’inspecteur du nœud
lorsqu’aucune broche de données Index n’est connectée. Un câble connecté
remplace toujours la valeur configurée.
