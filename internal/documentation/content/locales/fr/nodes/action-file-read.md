# Lire un fichier

## Objectif

Lit un fichier local approuvé sans modifier ses données. Sélectionnez
**Octets** ou **Texte** dans l’inspecteur pour l’unique broche résultat. Texte
est disponible uniquement avec du UTF-8 valide ; sinon, sélectionnez Octets.

## Exemple

`Surveillance de fichier → Lire un fichier → Analyser JSON → Boucle pour chaque`.

Avec **Encoder Base64** et **Décoder Base64**, choisissez explicitement les
représentations d’entrée et de sortie. Aucun nœud ne convertit implicitement
les données.
