# Reverse Array

## Purpose

Returns a copy of the list with the element order flipped.

## Example

`Sort Array (ascending) → Reverse Array` — a descending order that keeps the
stable ascending comparison for equal elements.

## Notes

The input list is never mutated, so other consumers of the same array pin
keep the original order. Combine with Sort Array for newest-first or
largest-last listings, or flip a history list so the latest entry comes
first.
