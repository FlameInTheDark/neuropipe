# Replace Word Text

## Purpose
Replaces every occurrence of a text fragment across the document body,
headers, and footers, then saves the file in place. Rewritten paragraphs keep
their paragraph and run formatting; occurrences split across Word runs are
matched because each paragraph is merged first.

## Example
`Cron Trigger` → `Replace Word Text (C:\Work\policy.docx, find "draft",
replacement "final")`.
