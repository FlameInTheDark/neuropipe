# Send Telegram Chat Action

Show a typing, upload, or location indicator in one chat. Actions map to
Telegram's documented set: typing, upload_photo, record_video, upload_video,
record_voice, upload_voice, upload_document, choose_sticker, find_location,
record_video_note, upload_video_note. The indicator disappears automatically
after roughly five seconds or when the bot sends the real message.
